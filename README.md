# umo-slim (羽毛bot簡易版)

Discord上で動作する、Google Gemini APIを活用したAIチャットボットであるumoの簡易版です。

## メインストリームとの違い
- slim版は、リプライチェーンの取得、toolの使用ができません。そのため、過去の会話の流れを理解することや、外部APIを利用した情報の取得ができません。

### メインストリームの機能を必要とする場合は、以下のリポジトリをご参照ください。
[umo](https://github.com/kz7c/umo)
